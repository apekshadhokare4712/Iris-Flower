# 🌸 Iris Flower Classification

## 📌 Project Overview

Iris Flower Classification is a Machine Learning project that predicts the species of an iris flower based on its sepal and petal measurements.

The model classifies flowers into three species:

* Iris Setosa
* Iris Versicolor
* Iris Virginica

## 📊 Dataset

The dataset contains four input features:

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width

**Target:** Iris Species
